# Project overview

ChoirLineup is a personal productivity application for singers participating in multiple choirs. It will organize choir memberships, reusable songs, learning materials, event lineups, preparation status, and personal practice. The initial release is personal rather than organizational: it does not include choir administrator roles or invitations.

Phases 1–7 are complete; Phase 8 native launchers are implemented, with Windows execution verification pending. The current application includes account authentication, a personal dashboard/workspace, profile editing and private profile pictures, choir CRUD with choir-specific voice parts, local workspace preferences, a reusable personal song library, custom categories, choir assignments, search/filter/sort, private learning material uploads, personal choir events, ordered event lineups with event-specific notes and preparation statuses, Practice Mode with in-app learning viewers and account-specific viewing progress, FullCalendar views with preparation reminders, account-scoped JSON/ZIP portability, and Windows/Linux launch scripts. The guiding goals are private per-account data, local self-hosting, clear responsive workflows, and portable personal records.
