# UI/UX guide

## Authentication

The application uses a warm, musical identity: forest green, sage, warm off-white, serif display headlines, and compact sans-serif form labels. Authentication is a split desktop layout with a single-column mobile form. React Hook Form validates required values and password confirmation; API errors and pending states appear at the form.

## Current workspace (Phase 7)

After sign-in, a responsive collapsible sidebar links to Dashboard, My Choirs, Events, Calendar, Song Library, Practice, My Profile, and Settings. Choir colors identify each personal choir in the sidebar, event cards, dashboard, and calendar. Choir records expand in place for details and edit/delete actions; deletion uses a confirmation dialog. The song library offers title search, choir/category/language/key/voice filters, recent/alphabetical sort, reusable choir assignments, and custom category management. The event list filters by active/completed/cancelled status and choir. Event details show choir, schedule, venue, deadline, status, and lineup preparation progress. The lineup supports drag-and-drop reorder with saving/error feedback, expandable event-specific details, and adding existing or newly created songs. Dashboard upcoming events link directly to event details. Practice opens an active event's ordered lineup, shows the current song, position, preparation status, and event notes, and provides previous/next controls. Marking a song Ready advances only when the user enables the automatic-next setting. A unified learning view lets the singer choose among PDF, image pages, YouTube, and uploaded video. Image books provide page navigation and a page arranger; PDF pages are selected in the viewer; uploaded videos and YouTube playback resume at their saved position. YouTube embeds keep a responsive 16:9 frame, with the iframe and its mount element filling that frame. Calendar opens in month view and supports week, day, and agenda views, respects the Sunday/Monday week-start setting, filters by choir, and shows choir-colored events, preparation deadlines, and reminders for incomplete songs. Click an event for its details or a practice reminder to start at the first song not marked Ready. Forms show validation, loading, empty, success, and error states. Mobile navigation uses a slide-in menu, and cards reflow for narrow screens.

Theme, calendar week start (Sunday/Monday), dashboard section visibility, and the automatic-next practice preference are stored in browser local storage. Profile pictures and song files load through the authenticated API client, not public media URLs. Per-user material page/video positions are stored on the server. The dashboard shows choir overview, event count, and the next active events with readiness counts. Settings includes JSON/ZIP export and import controls; replace mode requires explicit confirmation and merge is additive.
